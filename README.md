## 🌟 Overview
**EasySetup** is a premium SaaS platform designed to eliminate the friction of setting up a new laptop or developer environment. By leveraging official package managers (`winget` for Windows, `Homebrew` for macOS), EasySetup allows users to select their favorite apps, download a single script, and install everything completely hands-free in the background.

When things go wrong, our integrated **Session-Aware AI Support Agent** reads your terminal logs and instantly generates a safe fix command.

## ✨ Key Features

| Feature | Description |
|---------|-------------|
| ⚡ **One-Click Scripts** | Auto-generates lightweight `.bat` and `.command` scripts powered by `winget` and `brew`. |
| 🤖 **AI Support Agent** | A dedicated LLM workspace that analyzes `setup-log.txt` to debug failed installations instantly. |
| 🎓 **Student Mode** | Curated "Auto-Bundles" designed specifically for CS Students, Web Developers, and Data Scientists. |
| 🎨 **Premium UI/UX** | Built with an ultra-modern dark glassmorphic aesthetic and buttery-smooth `framer-motion` animations. |
| 🔒 **Authentication** | Secure user accounts and session memory to track generated scripts and diagnostic history. |
| 📦 **Massive Catalog** | Over 50+ curated applications covering Browsers, Dev Tools, Communication, and Utilities. |

## 🛠️ Tech Stack
- **Frontend Framework**: React 18 + TypeScript + Vite
- **Styling**: Tailwind CSS + Vanilla CSS (for glassmorphic utilities)
- **Animations**: Framer Motion
- **Icons**: Lucide React
- **Backend/Database**: Supabase (PostgreSQL, Edge Functions, Auth)
- **Scripting Engines**: Windows `winget`, macOS `Homebrew`

## 🚀 Getting Started (Local Development)

### Prerequisites
Make sure you have [Node.js](https://nodejs.org/) installed on your machine.

### 1. Clone the repository
```bash
git clone https://github.com/vicky2005-21/AVC09.git
cd AVC09
```

### 2. Install dependencies
```bash
npm install
```

### 3. Start the development server
```bash
npm run dev
```
The app will be available at `http://localhost:5173`.
